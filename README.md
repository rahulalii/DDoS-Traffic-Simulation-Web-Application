# 🛡️ DDoS Traffic Simulator

An interactive **DDoS Traffic Simulation Web Application** built with **HTML, CSS, and JavaScript** for learning and visualizing how excessive traffic can affect server capacity, request queues, and service availability.

## 🚀 Features

- 📊 Real-time traffic simulation
- 🎚️ Adjustable attack traffic using an interactive slider
- 🖥️ Server capacity visualization
- 📥 Request queue simulation
- ⏱️ Queue and waiting-time indicators
- ⛔ Denied-request visualization when capacity is exceeded
- 📈 Dynamic traffic calculations
- 📱 Responsive interface
- 🌙 Modern dark-themed UI
- 🔄 Reset simulation functionality

## ⚙️ How It Works

The simulator uses a configurable server capacity and legitimate traffic rate. Users can increase simulated attack traffic with the slider.

When total traffic exceeds the server's processing capacity:

**Traffic → Server → Queue → Capacity Limit → Denied Requests**

The interface dynamically displays the resulting queue size, waiting time, served requests, and denied requests.

## ⚠️ Educational Purpose

This project is strictly an **educational visualization**.

It does **not generate real network traffic, attack real servers, or perform an actual DDoS attack**.

The goal is to make networking and cybersecurity concepts easier to understand through an interactive browser-based simulation.
